# PR Review Skill

Independent, preferably read-only review. Compare task/acceptance criteria with diff, architecture/contracts, tests and relevant specialist concerns. Return PASS or CHANGES REQUIRED with blocking/non-blocking evidence using the standard PR review contract.

In `hackathon-24h` mode, timebox but do not skip review. Evaluate both correctness and engineering quality: duplication, unnecessary complexity or abstraction, oversized responsibilities, wrong-layer logic, inconsistent patterns, unnecessary dependencies, readability, and whether a simpler correct implementation exists.
