# Architecture Kickoff Skill

Use for new/in-progress planning. Ask one meaningful question at a time. Persist confirmed progress. Do not dump a giant questionnaire. If the user is unsure, explain options/tradeoffs and help estimate. Do not publish implementation tasks before explicit architecture approval.

When `operating_mode` is `hackathon-24h`, use the compact checklist in `docs/workspace/hackathon-mode.md`, choose architecture from the actual challenge rather than forcing a pattern, and obtain one explicit human architecture approval. Do not require every long-form Professional architecture document before implementation.
