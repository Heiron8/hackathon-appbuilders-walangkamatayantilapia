# Tanaw speech and picture asset sources

This pack contains 32 English WAVs and 32 original SVGs at the paths in the
canonical tanaw-v1 vocabulary. All pack assets are distributed under
GPL-3.0-or-later; the complete license is in GPL-3.0.txt. This asset license does
not change the license of unrelated application code.

WAV source: the corresponding plain English canonical label, synthesized locally
with eSpeak NG 1.52.0's **default en-us formant voice**, rate 145 words/minute,
mono PCM16 at 22,050 Hz. No Microsoft voice recording, external human voice model,
MBROLA voice, cloud inference or downloaded word recording is used.

eSpeak NG code, English voice/dictionary/phoneme source and license:
https://github.com/espeak-ng/espeak-ng/tree/1.52.0

Corresponding complete engine source archive:
https://github.com/espeak-ng/espeak-ng/archive/refs/tags/1.52.0.tar.gz

Official package used:
https://github.com/espeak-ng/espeak-ng/releases/download/1.52.0/espeak-ng.msi
SHA256 (locally computed; upstream release provides no digest):
7f673c709ea5dd579d3b5ebb98688cc575328a6ab7438d2bc405b88cedaeafb9

The official MSI is unsigned. It was administratively extracted into ignored
local tooling without system installation. Its CLI exited with Windows access
violation; the documented synchronous library API generated the WAVs successfully.
The package/executable/library are **not** distributed as application dependencies.
The exact library hash and voice settings are in ../speech-assets.json.

Preferred editable/generation source is supplied in this repository:
`docs/qa/prepare-speech-assets.py` and `shared/vocabulary.json`. Reproduce with:

```
python docs/qa/prepare-speech-assets.py --library "<extracted eSpeak NG>/libespeak-ng.dll"
```

SVG source: original vector drawings generated by Codex for Tanaw, embedded in
the preparation script and supplied as editable SVGs. No third-party pictograms,
photographs, emoji fonts, logos or external reference images were copied.
No contributor identity or clinical recognition validation is inferred.

Preserve this notice, the GPL text, the per-asset provenance manifest, the editable
SVGs and access to the label/generation and complete engine sources when sharing
the pack. This pack uses the same GPL terms conservatively for generated WAVs;
it does not rely on a claim that all synthesis outputs are automatically exempt.

All human intelligibility, recognition and real offline playback audits remain
PENDING until the tester provides actual results. Synthesis is mechanical and
may need pronunciation or symbol corrections after audition/review.
