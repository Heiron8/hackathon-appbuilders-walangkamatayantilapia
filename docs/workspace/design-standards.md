# Design Standards

## Governance flow

`requirements → user journeys → UX structure → wireframes → human approval → design context/system → frontend implementation → Design QA`

UI Designer and Frontend Engineer are different responsibilities. Frontend may flag design problems but should not silently redesign approved UX.

## Skill policy

- Core general design skill: **Impeccable** (enable only after pinning a version).
- Add stack/product-specific design skills only when relevant:
  - shadcn skill only for shadcn projects
  - mobile design skill only for native/mobile projects
  - chart/data-visualization skill only for visualization-heavy products
- Do not install/load broad overlapping design packs by default.
- External Figma/Canva/MCP/API integrations are optional enhancements, never core requirements.
